# 工作记录 2026-03-28

## 一、修复 A 股负价格问题

### 问题
- A 股历史价格出现负数（如茅台 -224 元），共 27,978 条异常记录
- 根因：akshare 前复权（qfq）算法对历史涨幅极大的股票会把早期价格调整为负值

### 修复
- 前复权（qfq）→ **后复权（hfq）**，后复权保持早期价格不变，向上调整后期价格，不会产生负值
- 清除全部 A 股旧行情并重新拉取，50 只全部成功
- 验证：负价格 0 条，茅台最低价 334.4 元（正常）
- 修改文件：`backend/pipeline/market_data.py`

### 附带修复
- `.env` 中新增的阿里云 SMS 变量导致 pydantic Settings `extra_forbidden` 错误
- 修复：`backend/config.py` 中 `model_config` 添加 `"extra": "ignore"`

## 四、修复详情页历史图表

### 问题 1：markPoint 显示 "value" 而非 Tier 标签
- 根因：ECharts markPoint 的 `formatter: '{value}'` 模板语法在 value 为字符串时行为异常
- 修复：改为函数式 `formatter: (p) => p.value`

### 问题 2：评分线条不连贯
- 根因：评分日期（如 `2024-12-31`）与价格日期（如 `2024-12-26`）不精确匹配，`[date, value]` 格式在 category 轴上找不到对应点导致断线
- 修复：
  - 评分日期对齐到最近的价格日期（`findNearestDate` 函数）
  - 评分数据改为与 priceDates 等长的数组（无评分位置填 null）
  - 添加 `connectNulls: true` 让点之间自动连线
- 修改文件：`frontend/src/views/CompanyDetail.vue`
