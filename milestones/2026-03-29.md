# 工作记录 2026-03-29

## 一、V1.0 达尔文流程评分引擎

### 核心变化
从「30 因子加权总分」重构为「四层漏斗流程模型」，忠实还原《What I Learned About Investing from Darwin》原书思想。

### 四层结构

```
全部 251 只股票
    ↓
Layer A: 硬排除（ROCE<20% / 财务脆弱 / 利润质量 / 治理稀释）
    ↓  230 家被排除
21 家合格
    ↓
Layer B: 质量评分（Q1 资本回报 40分 + Q2 护城河 35分 + Q3 资本配置 25分）
    ↓
Layer C: 估值闸门（按质量等级设不同 PE 阈值）
    ↓
BUY / WATCH / TOO_EXPENSIVE
```

### 硬排除规则（Layer A）
- **F1 ROCE 过滤**：5 年平均 ROCE < 20% → 排除
- **F2 财务脆弱**：利息保障 < 3 / 净负债/营业利润 > 4 / 流动比率连续恶化 → 排除
- **F3 利润质量**：OCF/NI < 0.7 连续两年 / FCF 累计 ≤ 0 → 排除
- **F4 治理稀释**：股本 CAGR > 3% / 商誉占比 > 40% → 排除

### 质量评分（Layer B，0-100 分）
- **Q1 资本回报质量（40 分）**：ROCE 水平 + ROCE 稳定性 + 现金转化
- **Q2 护城河与稳定性（35 分）**：毛利率稳定 + 收入连续性 + 经营利润率稳定 + 反脆弱
- **Q3 资本配置与治理（25 分）**：增量 ROCE + 稀释控制 + 股东回报 + 并购纪律

### 估值闸门（Layer C）
| 质量等级 | 条件 | BUY PE | WATCH PE |
|---------|------|--------|---------|
| Tier A | Q≥85, ROCE≥30% | ≤22x | ≤28x |
| Tier B | Q≥70, ROCE≥25% | ≤18x | ≤22x |
| Tier C | Q≥55, ROCE≥20% | ≤15x | ≤18x |

### 评分结果（2024-12-31）
| 排名 | 公司 | 质量分 | 状态 |
|------|------|--------|------|
| 1 | 贵州茅台 | 70.0 | TOO_EXPENSIVE |
| 2 | 五粮液 | 66.0 | TOO_EXPENSIVE |
| 3 | 迈瑞医疗 | 64.0 | TOO_EXPENSIVE |
| 4 | 山西汾酒 | 64.0 | TOO_EXPENSIVE |
| 5 | 泸州老窖 | 63.0 | TOO_EXPENSIVE |

230/251 家被硬排除（主因：ROCE<20%），21 家通过但估值偏贵。

### 已知问题
- 美股轻资产公司（Apple、Microsoft）因 Capital Employed 含大量现金导致 ROCE 偏低被误排除，后续需调整 ROCE 公式排除超额现金
- A 股 PE 计算因后复权价格导致虚高，需用不复权价格或市值/净利润
