## 三、M2.2 ROCE 严格口径

### 交付

`backend/metrics/roce.py`：
- `RoceComponents` dataclass：含 year / period_end / ebit / operating_current_assets / operating_current_liabilities / nwc_ex_cash / net_ppe / capital_employed / roce / notes / source_fact_ids
- `compute_roce_series(db, cid, year_range)` — 批量预拉缓存 + 逐年组装
- `compute_roce_year` — 单年便捷入口
- `evaluate_quality_gate(series, threshold=0.20)` — 5Y/10Y 门槛判定，`QualityGate` 含 fail_reason

### 严格口径实现

```
ROCE_t = EBIT_t / CapitalEmployed_t
CapitalEmployed_t = (CurrentAssets - Cash - ShortTermInvestments)
                   - (CurrentLiabilities - ShortTermDebt - CurrentPortionLTD - CurrentLeaseLiability)
                   + NetPPE
```

- EBIT 优先级：US = OperatingIncomeLoss；CN_A = ebit_reported → operating_income + interest_expense → total_profit + interest_expense
- NetFixedAssets 仅取 net_ppe，剔除 goodwill / 长期股权投资 / 无形资产 / 金融资产
- short_term_investments 缺失置 0 + `EXCESS_CASH_PROXY_LOW_CONFIDENCE` 标签
- 短期借款 / 一年内到期长债 / 一年内租赁负债缺失一律置 0
- CapitalEmployed ≤ 0 → `NEGATIVE_OR_ZERO_CAPITAL_EMPLOYED`，roce=None，不自动排除

### 质量门槛逻辑修正

**首版 bug**：`evaluate_quality_gate` 取"最近 5 个 valid 年份"，Apple/Visa 等 NEGATIVE_CAP_EMP 公司用早期 valid 年补窗口"假阳通过"。

**修正后**：取"最近 5 个**完整财年**"（含 invalid），近 5 年内 ≥ 2 年 NEGATIVE_CAP_EMP 或字段缺直接走 `Q5_RECENT_NEG_CAP_OR_MISSING` 人工覆核路径。

## 五、SEC 字段修补

### 起因

ROCE 首次全量回填后 Top 20 严重失真：Accenture 869% / Visa 622% / Apple 230% — 全是"大现金 + 小有形资产"公司。

根因：`backend/pipeline/sec_edgar/company_facts.py` 的 `CORE_CONCEPTS` 缺关键 tag，SEC companyfacts 拉取时 short_term_investments 等字段从未入库。

### 修补

`CORE_CONCEPTS` 增加 7 个 tag：

| 新 tag | 用途 |
|---|---|
| ShortTermInvestments | STI 主源 |
| MarketableSecuritiesCurrent | Apple 类公司用此字段记 STI |
| LongTermDebtCurrent | 一年内到期长债（PRD OperatingCurrentLiab 扣减项） |
| LongTermDebtNoncurrent | 非流动长期借款（净债计算） |
| OperatingLeaseLiabilityCurrent | 一年内经营租赁负债 |
| FinanceLeaseLiabilityCurrent | 一年内融资租赁负债 |
| CommercialPaper | 商业票据（Apple 等公司的"短期借款"） |

### 批量入口

`backend/pipeline/sec_edgar/backfill_tags.py` — 从 DB 取所有美股 cik，逐家调 `ingest_company`。fact_id 哈希按 concept + filed 唯一，新 tag 数据是纯增量。
